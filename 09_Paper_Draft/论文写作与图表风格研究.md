# 历届优秀建模论文研究与本项目写作规范

研究日期：2026-11-24  
用途：为2023 APMCM C题问题五建立论文结构与图表规范。本文只借鉴公开获奖论文的组织方式与可视化方法，不复制原文、图形或论证内容。

## 一、参考论文与选择理由

### 1. 2023 ICM E — 环境评价与优化

**2312411：Evaluation and Optimization of Light Pollution Based on EWM-TOPSIS**  
官方获奖身份：2023 ICM E Outstanding Winner；公开论文副本：  
https://reformship.github.io/pages/3competition/4mcm/MCM%20Outstanding/2023/E/2312411.pdf

可借鉴：
- 目录将模型准备、指标体系、模型建立、结果应用、敏感性、模型评价分层；
- 使用研究区地图表达空间差异；
- 敏感性分析单独成节，而非只在结论中简单提及。

需要改进：
- 本项目不能使用无单位或来源不清的“综合得分”代替物理排放量；
- 图表要标明空间范围、时间、功能单位和数据来源。

**2307336：Protect the Night, Control the Light!**  
官方获奖身份：2023 ICM E Outstanding Winner；公开论文副本：  
https://reformship.github.io/pages/3competition/4mcm/MCM%20Outstanding/2023/E/2307336.pdf

重点观察：
- Figure 2将四项任务分区展示，读者能迅速理解整体工作流；
- Figure 16用单因素扰动曲线比较不同指标对结果的影响；
- Figure 17把策略参数敏感性拆成并列子图；
- 图后立即解释哪个变量更重要，而不是只重复图中的数值。

本项目借鉴“一个图回答一个问题”的原则，但不沿用其EWM-TOPSIS模型。

### 2. 2024 MCM C — 多模块模型衔接

**2401298：Momentum Exists In Tennis Game As Residual Effect - A Dual-Temporal Bayesian Network Model**  
官方获奖身份：2024 MCM C Outstanding Winner，AMS Award；公开论文副本：  
https://reformship.github.io/pages/3competition/4mcm/MCM%20Outstanding/2024/C/2401298.pdf

可借鉴：
- Figure 1用分区框架图展示不同任务、模型和输出之间的关系；
- 先建立基础模型，再解释残差或扩展模型；
- 目录结构清晰，假设、符号、数据处理与模型建立相互衔接。

本项目的A物理清单、B两阶段GWP、C电池专项LCIA应在框架图中分成三条独立路径，并明确哪些路径不能相加。

### 3. 2022 MCM C — 敏感性与模型验证

**2200401：Grid the Profit: Adaptive Periodic Grid Model with ARIMA Prediction**  
官方获奖身份：2022 MCM C Outstanding Winner，SIAM Award；公开论文副本：  
https://reformship.github.io/pages/3competition/4mcm/MCM%20Outstanding/2022/C/2200401.pdf

可借鉴：
- 从基础策略到改进策略逐步建立模型；
- 通过回测、对照和敏感性分析解释模型有效性；
- 将模型评价放在主要结果之后。

本项目不能只写“模型具有鲁棒性”，而要给出电力因子、寿命里程变化后结果的实际幅度和盈亏平衡阈值。

## 二、官方写作要求

COMAP官方参赛说明强调：
- Summary Sheet放在正文之前；
- 清晰重述问题；
- 明确变量、假设和符号；
- 解释为什么选用相应模型；
- 展示主要推导与结果；
- 讨论误差、敏感性或稳定性；
- 说明模型优点和局限；
- 明确结论并规范引用。

官方说明：https://www.contest.comap.org/undergraduate/contests/mcm/instructions.php

## 三、本项目建议采用的论文结构

1. Summary Sheet / Abstract
2. Introduction
   - Problem Background
   - Problem Restatement
   - Our Work
3. Model Preparation
   - Data Sources and Data Processing
   - Assumptions and Explanations
   - Notations
4. Life-Cycle Inventory Construction
   - Functional Unit and System Boundary
   - Physical Pollutant Inventory
   - Vehicle Production and Energy WTW
   - Battery-Only LCIA
5. Two-Stage GWP Model and Results
   - Baseline Comparison
   - Electricity Factor Sensitivity
   - Lifetime Mileage Sensitivity
   - Break-Even Analysis
6. Model Evaluation
   - Strengths
   - Limitations
   - Further Improvements
7. Conclusion
8. References
9. Appendix: source parameters, detailed inventory, additional scenarios

最终目录需按原题五个问题的实际要求调整，不能为追求结构完整而新增与题目无关的模型。

## 四、图表规范

### 1. 图的职责

| 图号建议 | 图名 | 回答的问题 |
|---|---|---|
| Figure 1 | Overall Modeling Framework | 数据、模型、结果如何衔接？ |
| Figure 2 | LCA System Boundary | 哪些生命周期阶段纳入、哪些缺失？ |
| Figure 3 | Physical Inventory by Stage | 不同阶段的物理排放量如何分布？ |
| Figure 4 | Two-stage GWP Comparison | 可比车型的制造＋能源GWP差异多大？ |
| Figure 5 | Electricity-factor Sensitivity | 电力因子如何改变BEV结果？ |
| Figure 6 | Lifetime-mileage Sensitivity | 制造分摊里程如何改变结果？ |
| Figure 7 | Break-even Grid Factor | 电力碳强度何时会使技术排序反转？ |
| Figure 8 | Battery-factor Sensitivity | 电池化学体系和生产因子影响多大？ |

### 2. 统一视觉规则

- 使用白底、矢量图、简洁网格线；
- 同一技术类别跨图保持颜色一致；
- 图例名称使用ICEV、BEV-NMC、BEV-LFP等明确标签；
- 横纵坐标写全变量、单位和必要的归一化口径；
- 每张图配独立图注，说明样本、年份、情景和来源；
- 多组曲线优先使用折线图；阶段构成使用堆叠条形图；参数交互使用热力图；
- 缺失值用NA标记，不在图中画成零；
- 物种质量、CO2e和ReCiPe表征当量使用不同图表或明确分面，不混用同一纵轴；
- 关键结果图后跟一段解释，说明机制、变量敏感性及结论边界。

## 五、针对本项目的写作决策

1. 不把“全生命周期”写成已经完成的事实。正文使用“partial life-cycle inventory”或“two-stage GWP screening”。
2. A、B、C三条核算路径先说明物理含义，再给结果，不能在结果章节中突然合并。
3. 所有敏感性结果同时报告参数范围、基准值、结果变化和是否改变结论。
4. 对赛题时点后的2023官方电力因子，放在“retrospective validation”或附加情景中，不写成参赛时已知信息。
5. 摘要最后定稿；应包含模型、关键数值、最重要结论与主要限制，避免空泛宣传。
6. 论文主文只放最能解释模型的图表；详细因子、原始数据、完整场景矩阵放入附录或资料仓库。
