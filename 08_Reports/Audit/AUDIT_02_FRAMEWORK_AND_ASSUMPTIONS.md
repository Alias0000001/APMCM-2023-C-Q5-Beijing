Baseline e11c1e0b8044cbdc3dcc895b6a884fd259afd8af; Q5 only. Audit-01 scope retained. No changes to main or existing R9.7A–F baseline. This is an independent structural audit and supplemental test, not a new empirical inventory.

## Model logic
For target P=1e6 urban residents, use reference-city matched municipal stock/person and modeled mileage: V_P=P(N_r/P_r)d_y gm; V_B=P(V_B,r/P_r)b. Stock to activity is p_k=N_k d_k / sum_j N_j d_j, not generally stock proportion. V_ik,s=V_i p_ik,s. Carrier quantities V*u (MJ/km, L/km or kWh/km); included-stage GWP=sum V*(manufacturing/lifetime + fuel/electricity WTW) with compatible units; separate road pollutant sum V*EF. This directed chain is closed and computable for defined scope. No regression or optimization is necessary for a counterfactual accounting question; do not claim prediction, causation or general population scaling. Production is steady-state lifetime allocation, not all stock manufactured this year. S3−S2−S1+S0=0 for additive fixed-VKT model; no synergy claim. S4 changes operational grid intensity only. Audit-05 must independently verify every remaining metric and units; Audit-04 must evaluate source scope and missing stages.

## Assumption decisions
1. **Population / geography (A-002b):** urban share r=P_urban/P_all=0.875704. For a matching urban numerator fraction theta, V_urban per capita / V_all per capita=theta/r. theta is not observed; assigning all municipality numerator to urban population gives 1/r=1.141939 stress, not a new urban estimate, nor a general upper bound for other cities. Operator VKT may cross boundaries. With the same factor applied to both modes, annual GWP S0=648.380 kt, S3=556.099 kt, percentage unchanged. Do not combine this scalar with an equivalent ownership or supply adjustment without justification. Existing independent g,m,b transfer remains valid conditional stress. Audit-03/06 verify spatial evidence and avoid duplicate multipliers.
2. **Mileage:** 2023-08-28 China Business Journal report https://www.sohu.com/a/715705099_100106037 describes central-city private car dispatch 46.1% and Beijing private car daily travel 49.9 km in separate statements; it does not state that the latter is conditional on dispatched cars or the same sample. 8396.4235 km/car-year is a conditional structural proxy, alternative 18213.5 already in D. Do not relabel dispatch as fraction of mileage in city. Audit-03 checks original annual report; keep both alternatives if unavailable.
3. **Propulsion allocation:** baseline equality of annual per-vehicle VKT is a simplifying assumption, not a data identity. Normalize stock weights by relative mileage. Private NEV stock s=.05/.08/.1158 (upper design value rounded from all NEV passenger stock divided by private stock, not observed), BEV fraction t=.6/.778/.9 (outer design stress), bus mixed BEV q=.6/.8/1, relative NEV car mileage and BEV bus mileage .8/1/1.2. Keep mode VKT fixed; these are design points, not distributions. Unknown buses assigned to diesel/gas ratio, before normalization. This explicitly addresses missing composition axis in previous 14580 grid. 243 paired sets ×6=1458 rows, S3 paired reduction 12.873%–15.290%; bus-first NOx preference 243/243 at reference China V factors. Do not equate with joint energy/lifetime grid; Audit-06 decides whether coupled stress is material.
4. **Fixed VKT vs PKM:** retain fixed VKT primary; conditional o_i weighted by VKT, PKM=V_i o_i. For fixed observed/proxy S0 service, define technology-relative loading w_k, calibrate o_{ik}=o_{i0} w_k/sum p_{ik,0} w_k. Then all stress cases share the same S0 proxy; equal-service VKT ratio remains exactly (sum p0*w)/(sum ps*w), so existing D equal-service annual GWP unchanged. Existing D absolute PKM under lower/higher occupancy varies S0 by design, should not be called a fixed common PKM across different cases. Audit-06 may add calibrated intensity outputs; Audit-03 no re-search without new path. No modal substitution or schedule/capacity guarantee; distance-weighted occupancy not boarding density.
5. **S−1 (A-004):** current diesel/gas mix is a natural all-fossil counterfactual preserving observed conventional fuel ratio, not a historical measured fleet. Retain as primary; all-diesel alternative S−1 GWP 598.400 kt vs 584.589 kt; NOx 452.518 vs 728.715 t; PM2.5 12.445 vs 7.645 t. S0–S4 unchanged. A-004 definition and reference comparison completed; broader energy/fleet coupling in Audit-06.
6. **PHEV/energy/production:** UF is conditional electric-distance share; CS/CD consumption proxies, no CD fuel in reference; eta applied once, S4 only use-phase electricity. Production/lifetime steady state; bus historical load used only to undo source normalization; no multiply by target PKM occupancy again. Current B mixed_diesel/mixed_gas energy cases change residual technology but C production remains hybrid. This inconsistency is material for jointly interpreted sensitivity; do not claim all nested sets fully technology-consistent. Audit-06 must synchronize allocation across energy, production and exhaust or explicitly keep energy-rate-only stress. Data/source scope, battery chemistry and omitted maintenance/EOL transferred to Audit-03/04.
7. **Continuous adoption:** for independent replacement of fraction x_P and x_B of each S0 mode VKT mix with BEV, G(x_P,x_B)=G0+x_P(G2-G0)+x_B(G1-G0). Valid for fixed VKT, constant factors, same grid; endpoints reproduce S0–S3. This is a response surface, not a time forecast or stock share. For current reference, annual GWP kt = 567.788656 - 71.546778 x_P - 9.263969 x_B. S4 requires separate grid term. No need to add a seventh baseline scenario.
