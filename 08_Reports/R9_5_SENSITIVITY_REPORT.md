# R9.5 — 生命周期GWP敏感性、盈亏平衡与电池因子分析

日期：2026-11-24  
研究对象：北京2023年交通活动折合100万人口代表城市  
版本定位：R9.4三轨整合后的参数敏感性与阈值分析  
核心边界：两阶段气候变化筛查（车辆生产 + 能源WTW）；不是完整cradle-to-grave LCA。

## 1. 本轮工作与边界原则

R9.5不再扩充主体模型，而是检验R9.4中能够同口径比较的私人ICEV、BEV-NMC、BEV-LFP两阶段GWP结果，对三个主要参数进行敏感性分析：

1. 电力碳强度；
2. 车辆寿命里程（制造负荷分摊）；
3. 动力电池制造GWP因子。

同时求解BEV相对于ICEV的电力碳强度盈亏平衡阈值。

**最重要的口径区分：**
- 严格赛题时点文献情景：Peng2017的两组WTW因子，均为赛题前已发表文献。Table 8为主情景，正文168 gCO2e/MJ作为来源内部差异敏感性。
- 回顾性更新情景：生态环境部2025年公布的2023年全国电力碳足迹因子0.6205 kgCO2e/kWh，以及2025年末公布的北京2023年电力平均CO2因子0.5554 kgCO2/kWh。它们反映2023实际年度数据，但发布晚于2023赛题，不能放进严格竞赛时点主情景。
- 0.6205 kgCO2e/kWh是全国电力生命周期碳足迹因子；0.5554 kgCO2/kWh是北京地理平均电力CO2排放因子，仅覆盖发电CO2直接排放。二者的范围和单位不同，不相互替代，也不能与Peng WTW因子混为一个连续的同口径样本。
- Sun2020、ICCT2021、Hao2017、Lai2022电池因子均作为独立电池模块。Qiao2017的BEV整车生产因子已包含初始动力电池，故电池GWP不再叠加到两阶段整车GWP。

## 2. 两阶段GWP模型

### 2.1 车辆单位里程强度

对车辆类型 (v)，定义：

[
I_v(L,EF_e)=rac{M_v}{L}+E_v
]

其中：
- (I_v)：两阶段气候变化强度，kgCO2e/vehicle-km；
- (M_v)：车辆cradle-to-gate生产GWP，kgCO2e/vehicle；
- (L)：车辆全寿命行驶里程，vehicle-km；
- (E_v)：燃料或电力WTW排放强度，kgCO2e/vehicle-km；
- (EF_e)：电力生命周期排放因子，kgCO2e/kWh。

ICEV能源强度：

[
E_{ICEV}=rac{Q_g}{VKT_{ICEV}}ho_g LHV_g EF_g
]

BEV能源强度：

[
E_{BEV}=rac{Q_e}{VKT_{BEV}}EF_e
]

年度两阶段GWP：

[
GWP_{v,annual}=rac{VKT_v I_v}{1000}
]

其中年度VKT单位为km，最终结果单位为tCO2e/year。

### 2.3 电力因子敏感性

严格WTW敏感性只采用Peng2017内部两组电力因子：

| 情景 | 电力因子 | 含义 |
|---|---:|---|
| Peng2017正文替代值 | 0.6048 kgCO2e/kWh | 168 gCO2e/MJ |
| Peng2017 Table 8主值 | 0.73224 kgCO2e/kWh | 203.4 gCO2e/MJ |

二者属于同一文献的数值差异情景，不取平均。

另将MEE2023全国电力碳足迹因子0.6205 kgCO2e/kWh用于回顾性敏感性比较。由于其核算方法、数据年份和地域范围与Peng2017不同，结果标记为方法/时间更新转移情景，而不是严格同口径WTW对照。

## 3. 计算结果

### 3.1 电力因子敏感性

基准寿命200,000 km：

| 电力因子情景 | BEV-NMC强度 | BEV-LFP强度 | ICEV基准强度 |
|---|---:|---:|---:|
| Peng正文替代WTW：0.6048 | 166.95 | 167.80 | 265.54 |
| Peng Table 8 WTW：0.73224 | 186.33 | 187.17 | 265.54 |
| MEE 2023全国电力PCF：0.6205 | 169.34 | 170.19 | 265.54 |

单位：gCO2e/vehicle-km。MEE情景是全国电力生命周期PCF的回顾性转移，不是北京2023赛题时点可用的地方WTW因子。

Peng2017的两个严格文献情景下，BEV-NMC强度分别为166.95和186.33 gCO2e/km。其相对于ICEV基准的差异约为37.12%和29.83%。因此，电力因子选择会显著影响减排幅度，但在这两个文献情景下未改变本模型的技术排序。

### 3.2 车辆寿命里程敏感性

采用Peng2017 Table 8电力WTW因子0.73224 kgCO2e/kWh：

| 寿命里程 | ICEV | BEV-NMC | BEV-LFP | BEV-NMC相对ICEV变化 |
|---:|---:|---:|---:|---:|
| 100,000 km | 315.46 | 261.35 | 263.04 | -17.15% |
| 150,000 km | 282.18 | 211.33 | 212.46 | -25.11% |
| 200,000 km | 265.54 | 186.33 | 187.17 | -29.83% |
| 250,000 km | 255.55 | 171.32 | 172.00 | -32.96% |
| 300,000 km | 248.90 | 161.32 | 161.88 | -35.19% |

单位：gCO2e/vehicle-km。

随着车辆寿命里程增加，制造阶段负荷被分摊到更多vehicle-km，三类车辆强度均下降。由于Qiao生产因子下BEV制造负荷与ICEV不同，寿命里程变化也会改变制造阶段差值；在当前参数下，寿命越长，BEV相对优势越明显。

150,000 km与200,000 km分别对应Yang2021和Qiao/TLCAM的文献分摊口径。100,000、250,000、300,000 km属于D级外扩压力测试，不应写成北京车辆寿命实测。

当实际电力WTW因子低于 (EF_e^*) 时，当前参数组合下BEV两阶段GWP低于ICEV；高于阈值时排序反转。

| 寿命里程 | BEV-NMC阈值 | BEV-LFP阈值 |
|---:|---:|---:|
| 100,000 km | 1.088 | 1.077 |

在200,000 km基准寿命下，BEV-NMC的盈亏平衡电力WTW因子约为1.253 kgCO2e/kWh，高于Peng2017 Table 8的0.73224 kgCO2e/kWh。该阈值只对当前汽油消耗、电耗、制造因子、寿命和WTW边界成立；不是脱离车型与地区条件的普遍结论。

### 3.4 电池制造因子敏感性（独立模块）

电池制造强度计算：

[
I_{battery}=rac{C_{battery}F_{battery}}{L_{battery}}
]

其中 (C_{battery}) 为电池包容量，(F_{battery}) 为单位容量制造GWP因子。BEV使用40kWh参考容量，PHEV使用12.8kWh参考容量；后者的实际化学体系未核实。

在150,000 km电池服务寿命下：
- BEV电池制造强度约13.60–36.53 gCO2e/vehicle-km，对应文献因子51–137 kgCO2e/kWh；
- PHEV探索性电池模块约4.35–11.69 gCO2e/vehicle-km；
- Sun2020 NCM622基准因子124.48 kgCO2e/kWh，对应BEV电池模块约33.19 gCO2e/km、年度约14,183.27 tCO2e；
- Sun2020假设100%湿法回收后的净因子93.57 kgCO2e/kWh，对应BEV约24.95 gCO2e/km，但这是包含假设回收信用的净情景，不能与纯cradle-to-gate生产因子混同。

ICCT、Hao、Lai和Sun的电池因子具有不同年份、化学体系及核算边界，故本表是文献因子敏感性，不代表北京2023车队实际电池化学结构。

**禁止将本节电池模块再加到Qiao BEV整车生产GWP中。** Qiao2017的BEV整车生产因子已包含初始电池。电池因子敏感性只用于拆分观察电池模块本身的贡献。

### 3.5 回顾性电力数据交叉核验

生态环境部2025年1月发布的2023年全国电力碳足迹因子为0.6205 kgCO2e/kWh。将其转移至当前BEV用电活动量，BEV电力组件约94.32 gCO2e/km；加上Qiao整车生产分摊后，BEV-NMC约169.34 gCO2e/km。该结果是“2023全国PCF因子 + 2015汽油WTW + 2017整车生产”的混合年代情景，只用于回顾性敏感性。

生态环境部、国家统计局2025年12月公布的北京2023年电力平均CO2排放因子为0.5554 kgCO2/kWh。对应BEV用电发电环节约84.42 gCO2/km，年度约36,070.95 t CO2。此处是发电端CO2直接排放，不包含上游燃料链、发电设备建设等生命周期环节，不能加上制造GWP后宣称是完整WTW总量。

## 4. 结果解释与模型边界

1. 当前两阶段模型中，BEV-NMC在Peng2017 Table 8主情景下为186.33 gCO2e/km，低于ICEV的265.54 gCO2e/km；这是给定跨研究参数下的筛查结果，不是完整LCA结论。
2. 电力碳强度与寿命里程均影响减排幅度。当前情景内未出现排序反转；盈亏平衡阈值给出未来电力结构变化下的判别条件。
3. 电池制造因子差异会显著改变电池模块本身的强度，但由于整车制造因子已含初始电池，当前不能把电池模块直接加回整车GWP。
4. 物理污染物清单A轨、两阶段GWP B轨、电池ReCiPe C轨仍保持互斥。NOx、SO2、PM2.5物种质量不得与ReCiPe表征当量直接相加。
5. PHEV与公交尚无匹配的整车制造GWP，完整两阶段总量保持NA。
6. 公交天然气燃料CNG/LNG组成和热值、未分配混合动力活动量、公交制造、非尾气排放、车辆装配及完整报废回收仍是后续主要缺口。
7. 2023北京电力因子和全国PCF因子均在赛题之后公布，严格竞赛版本不得引用为赛题时点已知数据；可以作为当前研究的回顾性验证。
