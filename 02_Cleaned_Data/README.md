# Cleaned data conventions

- Files in this directory are structured or transformed analysis inputs, not original source records.
- Each row must retain a source ID and evidence class.
- Official observations retain the published unit and statistical scope.
- Derived population-scaled values must be labelled class C and retain the scaling factor and formula.
- A missing value stays blank; do not fill it with an undocumented estimate.
- Do not annualize medians or percentiles as though they were annual means.
- Keep passenger trips separate from passenger-kilometres.
- Keep aggregate new-energy vehicle counts separate from BEV/PHEV subtypes.
