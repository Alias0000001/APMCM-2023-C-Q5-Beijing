# Raw data rules

1. Place downloaded source files here without renaming or editing the original bytes.
2. Record the exact source URL, download date, observation period, geographic boundary, and any access limitations in RAW_DATA_MANIFEST.csv.
3. Never overwrite a raw file with a cleaned version. Cleaned copies belong in 02_Cleaned_Data.
4. Verify checksums where the publisher provides them.
5. If a source is only available as a web page, keep the canonical URL and record that no local original is archived.
6. Do not reconstruct missing raw observations from plots, medians, audit summaries, or model outputs.
