# First-pass S0 population scaling

## Method

The 2023 Beijing year-end resident population is 21,858,000. The target representative city has 1,000,000 residents.

\[
s=\frac{1,000,000}{21,858,000}=0.045749839876\;.
\]

For an extensive indicator with a compatible source boundary:

\[
X_{1m}=sX_{Beijing}.
\]

The script scales official vehicle counts and annual activity totals. It does not scale the electricity emission factor because it is an intensity, not an extensive quantity.

## Output

The output is written to:

- `../02_Cleaned_Data/beijing_2023_population_scaled_inputs.csv`

Every output row is class C (derived). The decimal values are expected values from a mathematical scaling assumption; fractional vehicle counts are not literal counts.

## Critical limitations

1. Linear population scaling is a baseline assumption. It does not model density, urban form, modal split, congestion, or non-linear network effects.
2. Private passenger stock is a count, not VKT. No private-car annual VKT is generated by this script.
3. The aggregate new-energy private passenger count is not split into BEV and PHEV.
4. Public bus source categories and operator totals remain separate. The source wording 公共电汽车 is not a verified BEV propulsion classification.
5. Passenger trips are not passenger-kilometres. No bus PKM is inferred.
6. Operator-level bus totals are scaled using Beijing population as a first-pass approximation; this does not prove that operator service coverage is proportional to population.

From the repository root:

```bash
python 06_S0_Calculation/scale_official_inputs.py
```
